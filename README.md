# KOL Scanner — Release

Repo này chỉ chứa **bản build (installer)** của KOL Scanner, publish tự động qua GitHub Actions từ repo source [`kol_interlink`](https://github.com/SofinHolding/kol_interlink) mỗi khi tag `v*` được push.

Tải bản mới nhất ở mục [Releases](https://github.com/SofinHolding/kol_interlink_release/releases).

Repo được dùng làm nguồn auto-update (`electron-updater`) cho app đã cài trên máy user — không chứa source code.
